# SPPG Cilacap Cilacap Selatan Tambakreja 2 — Prototype v2

## Pembaruan versi 2
- Nama menu pada Perencanaan Produksi menggunakan kolom pencarian/autocomplete.
- Prediksi menu mengambil nama dari Database Resep.
- Kategori menu ditampilkan tepat di bawah kolom nama menu dan dapat digunakan untuk menyaring pencarian.
- Kategori resep menggunakan pilihan: Ayam, Telur, Sayur, Ikan, Daging, Lauk lainnya, dan Lainnya.

## Publikasi GitHub Pages
1. Ekstrak ZIP.
2. Unggah isi folder (index.html, README.md, .nojekyll) ke root repository GitHub.
3. Commit changes.
4. Buka Settings → Pages.
5. Pilih Deploy from a branch, branch `main`, folder `/ (root)`, lalu Save.

## Catatan
Prototipe ini masih menyimpan data di localStorage browser. Fitur multiuser/login belum aktif dan membutuhkan backend/database online.
